# Карта источников NSSD Call Center BI

Аудит через Google Sheets API с правами чтения. Проверены метаданные четырёх книг, заголовки, структура диапазонов и контрольные формулы. Какая доля строк имеет ключи и насколько полна история, требует отдельной сверки. Часовой пояс книг: Europe/Moscow. Данные за пределами подтверждённого покрытия считаются недоступными.

## Производные вкладки

Единый_факт собирает операционный день из Операционные_данные A5:X303, направления из Передачи_Менеджерам A5:E50500 и договоры из Договоры_Ноябрь A5:E124. Использовать для проверки зерна и сверки, не второй раз считать события. Диапазоны формулы ограничены и сами по себе не гарантируют полноту.

Ежедневный_отчет, Дашборд, рейтинги, региональные и персональные аналитики — контрольные отчёты. График_КЦ_импорт, Импорт_расписания и Синхронизация_статусов_лидов — копии или преобразования. Бот_уведомления не считать журналом всех изменений статуса. Сравнение 01-16 Окт Ноя фактически сравнивает 01–16 октября с 01–17 ноября; результат непригоден как сопоставимая база. Нужен октябрьский первичный источник или верифицированный срез 01–16 ноября.

## Идентификация и качество

- Из поддерживаемых ссылок Bitrix извлекать числовой lead ID с пространством имён CRM. ID передачи из расписания хранить отдельно. Повторную передачу и повторную запись одного события учитывать раздельно.
- ФИО хранить в исходном виде и сопоставлять через справочник алиасов по роли. Нормализация пробелов и регистра не разрешает совпадения между разными сотрудниками.
- МСК → Москва, СПБ → Санкт-Петербург. Город сотрудника и регион лида — разные измерения.
- Строки без ключей, конфликты и неполное покрытие считать отдельно. Договоры без ID не включать в уникальную когортную воронку. Исторические статусы не реконструировать из текущего поля G.
- Файлы с персональными строками и зарплатами не сохранять в Git.
